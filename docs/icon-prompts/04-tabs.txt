Draw icons in exactly the style of the attached reference image, which is the
approved icon set for this app. Match its line weight, its simplicity and its
level of detail.

- Line art only. Every shape is an open stroke with rounded ends. No filled
  shapes, no shading, no double lines.
- Simple and plain. Draw the object, not a detailed illustration of it.
- Draw each icon as large as it will go in its canvas, centred.
- One icon per file.

FILE FORMAT

- SVG, viewBox="0 0 64 64", no width or height attributes
- fill="none", stroke="currentColor", stroke-width="1.5",
  stroke-linecap="round", stroke-linejoin="round"
- Any number of <path>, <circle>, <line>, <polyline> elements
- No transform attributes - bake positions into the coordinates
- Filename is the icon name exactly, e.g. barbell.svg
