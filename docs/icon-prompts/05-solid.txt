Draw icons to match the attached reference image, but these ones are SOLID
FILLED shapes rather than line art - they are used very small, where a thin
line disappears.

- Solid filled silhouettes. Any internal detail is cut out of the shape as a
  hole, not drawn as a line.
- Simple and plain. No shading, no gradients.
- Draw each icon as large as it will go in its canvas, centred.
- One icon per file.

FILE FORMAT

- SVG, viewBox="0 0 64 64", no width or height attributes
- One <path> with fill="currentColor" and fill-rule="evenodd", no stroke
- No transform attributes - bake positions into the coordinates
- Filename is the icon name exactly, e.g. statusComplete.svg
